# Frontier Outpost

The playable 64×64 ridge park is generated by `scripts/create-park-assault.py --playable`.
`scenario.json` describes starting actors, the carousel objective, and the defense waves;
`mapping.json` preserves the destructible gate rule. Generated parks and native maps stay
under ignored `run-data/`.

Run `scripts/project.sh play frontier-outpost` after building the engines.
