# OpenRCT2 native patch

The native render registry, paint hook, and script binding will be developed against the pinned checkout in `../upstream/openrct2`. Keep changes as reviewable patches or a local fork revision here; do not edit the upstream checkout without recording the diff.

No renderer patch exists yet. The first milestone is to prove the actual OpenBW/BWAPI unit simulation and the stock OpenRCT2 multiplayer build.
